# 수도 건설 메뉴

번호는 각 페이지의 3×3 버튼 위치(1~9)입니다. 전체 건물의 일련번호가 아닙니다.

require_data.json의 unit_links에서 연무관·군비 공방·병법원은 기존 38번 WORD 프로그램(군영 155 보유 → 종료), 기사단 회관은 7번(병법원 160 보유 → 종료)에 연결합니다. 마법 연구소는 361번(수도 173 보유 → 종료)을 유지합니다. 요구사항 영역을 확장하거나 새 프로그램을 쓰지 않습니다. 네 건물의 버튼은 Can Create Unit/Building 조건으로 활성화 여부를 표시하며 construction.canBuildAt에서도 현재 선행 건물 보유를 검사합니다. 선행 건물이 없어져도 기존 후속 건물은 제거하지 않습니다.

건설 단축키는 버튼 위치 순서의 Q/W/E, A/S/D, Z/X를 사용합니다.
페이지 전환은 네이티브 Change Displayed Buttons 동작을 사용합니다.
두 번째 페이지는 초기화 때 제거하는 수도 비콘의 버튼셋을 예약하며, 수도 유닛 자체는 바꾸지 않습니다.

## 메뉴와 실제 건설의 경계

대도시의 배치 크기와 충돌 범위는 Arbiter Tribunal의 기본 DAT 값을 사용합니다. 수도 승계 공간 확보를 위해 추가했던 128×128 확대는 제거했습니다.

`modules/nexus_menu.py`의 `BUILDINGS`에서 역할 이름, 페이지, 버튼 위치, 대상 UnitModel, 표시 이름, TBL ID를 관리합니다.
대도시는 600금, 건설 시간 720프레임이며 src/data/diplomacy.json에서 관리합니다. 나머지 건설비는 resource/buildings.json에서 관리합니다. 군영 150금, 병법원 200금, 연무관·군비 공방·기사단 회관·마법 연구소 각 100금, 회복 군막 150금입니다. 모두 가스 비용은 0이며 엔진이 건설 시 차감합니다. 연구 건물 자체는 저렴하게 유지하고 연구에 투자하게 합니다. 다음 작업은 연무관·군비 공방·기사단 회관의 연구 내용을 정하는 것입니다.
선행 조건이 있는 네 건물은 요구사항으로 버튼 사용 가능 여부를 결정합니다. 나머지 건물은 Always 조건을 유지하며 데이터 로딩 방식은 변경하지 않습니다.
TBL 건설 설명은 단축키 뒤에 유닛 생산 한정자 `\x01`을 사용합니다. 페이지 전환은 일반 설명 한정자 `\x00`입니다.

수도의 건설 명령은 기존처럼 `nexus.buildRemote`에서 감지하여 프로브 대리 건설로 실행합니다.
두 페이지의 여덟 건물을 모두 대상으로 하며, 테란 건설 명령에 대한 기존 SCV 경로도 유지합니다.
대리 일꾼은 UnitGroup으로 관리하고, 건설·수리 관련 명령을 벗어나면 제거합니다. 죽은 항목도 매 틱 정리합니다.

`modules/construction.eps`의 `canBuildAt(unit : CUnit)`은 대리 일꾼을 생성하기 직전에 호출하는 거부 조건 연결 지점입니다.
수도 CUnit만 전달하며 함수 내부에서 건설 큐 필드에 `epdswitch(unit + 0x98 / 4, 0xFF)`를 적용해 건물별로 검사합니다. 소유자는 필요한 분기에서만 읽고, 추후 좌표 검사도 필요한 분기에서만 수행합니다. 호출부의 중복 건설 대상 검사와 건물 ID 읽기는 제거했습니다.
현재는 대도시 건설 한도(도시 3개당 1개, 최소 1개)를 엔진 전체 유닛 수로 확인합니다. 건설 중 건물과 승계된 수도도 한도에 포함합니다. 대리 프로브의 예약 카운터는 사용하지 않습니다. 연속 건설로 발생한 초과 건물은 trackNewUnits에서 걸러내고 건설비를 반환합니다. 이후 영토·거리 등 세부 조건을 추가합니다.
false를 반환하면 수도의 건설 명령만 초기화하고 대리 일꾼을 생성하지 않습니다.
자원 차감은 실제 건설의 엔진 동작에 맡기며 별도로 중복 차감하지 않습니다.

## 후속 구현할 설계

- 대도시의 건설 한도·수입·수도 승계는 구현했습니다. 수치와 승계 규칙은 INCOME.md에 기록합니다.
- 군영 자동 생산은 구현했습니다. 버튼셋·훈련 목록·랠리·점령 처리는 ARMY_CAMP.md에 기록합니다.
- 병법원: 군영을 하나 이상 소유해야 건설 가능. 수도 명령을 처리할 때 건설 조건을 확인한다. Q 공병(80금/288프레임), W 경기병(180금/432프레임), E 기사(360금/720프레임)를 엔진 대기열로 개별 생산한다. R 랠리와 Esc 마지막 훈련 취소를 제공한다. 군영의 반복 생산·시간 보정은 적용하지 않는다. 생산 요구사항은 기존 빈 조건 프로그램에 연결하며 새 요구사항 영역은 만들지 않는다. TBL 1589~1596을 사용하고 생산 설명 한정자는 0x01이다.
- 연무관: 창병 이동속도 연구 예정. 구체적인 효과와 방식은 후속 확정한다.
- 군비 공방: Q 경보병 사업(400금/1440프레임), W 경보병 속업(400금/1440프레임), E 장궁병 사업(600금/1920프레임), Esc 진행 연구 취소. 각각 네이티브 Grooved Spines·Muscular Augments·Singularity Charge를 사용한다. 모든 연구를 완료할 수 있으며 연구 순서를 선택한다. 공격력·방어력은 땅 확보·레벨업 체계에서 처리한다.
- 기사단 회관: Q 공성 진지술 연구(600금·1440프레임), Esc 연구 취소. 사용하지 않는 Tank Siege Mode 기술을 재사용한다. 연구 완료 후 공병이 150금에 공성 터렛을 건설한다. 기술 연구 요구사항 23번은 기존 시즈 연구 프로그램에서 Machine Shop 종류 검사만 제외한 접미부로, 연구 중복·진행 처리는 엔진이 맡는다. 터렛 요구사항은 기존 유닛 영역의 빈 400번 WORD에 FF0F·기술 5·FFFF를 배치한다. 전체 요구사항 길이는 늘리지 않는다. 연구 설명 한정자는 기존 시즈 연구와 같은 0x04이며 터렛 건설 설명은 0x01이다. 기사 강화 연구는 후속 작업이다.
- 마법 연구소: 영웅 강화 연구.
- 회복 군막: 세력별 개수 제한. 주변에서 가드 중인 유닛만 회복하며 공격 중·홀드 중에는 회복하지 않음.

창병·기사·영웅의 추가 연구와 회복 동작은 후속 작업입니다. 병법원 수동 생산·공성 진지술·군비 공방 연구는 코드에 연결했으며 빌드·인게임 확인은 아직 하지 않았습니다.

새 메뉴 TBL은 1548~1565번을 사용합니다. 기존 FranceDp 계급용 빈 버퍼(1302~1324)의 해시 문자 패딩만 제거하고 선행 바이트 및 기존 ID를 유지하여, 고정 TBL 복사 영역을 확장하지 않습니다.
