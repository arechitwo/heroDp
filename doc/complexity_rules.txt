//  기준: 입문자 10분 파악 / 한 판 20~30분
// ============================================================


// ============================================================
//  [원칙] 3가지 핵심 설계 기준
// ============================================================

//  1. 플레이어가 기억해야 할 것은 3가지 이내
//     → 병종 상성, 도시 점령, 자원 관리 이 셋만 머릿속에 있으면 게임 가능
//
//  2. 처음 보는 플레이어가 1분 안에 행동 선택 가능해야 함
//     → UI 없이 채팅 커맨드만으로 진행하는 구조는 지양
//     → 선택지는 화면에 항상 보여야 함
//
//  3. 판이 30분을 넘기면 설계 실패로 간주
//     → 수입·전투 속도를 조정해서 판을 강제로 끝낼 수 있는 장치 필요


// ============================================================
//  [룰 01] 가스 액션 단순화
// ============================================================

//  현재: 10종 (전투 4 + 영토 3 + 외교 3)
//  변경: 4종으로 축소

//  남기는 것 (직관적이고 즉각 효과가 보이는 것)
//  ㄴ ActionRecruit(15)    — 병력 즉시 소환 (가장 직관적)
//  ㄴ ActionHeal(30)       — HP 회복 (전투 중 즉각 체감)
//  ㄴ ActionFortify(20)    — 방어 강화 (수비 전략)
//  ㄴ ActionMercenary(25)  — 용병 고용 (재미 요소)

//  제거하는 것 (학습 비용 대비 효과 낮음)
//  ㄴ ActionCharge         → 상성으로 대체 가능
//  ㄴ ActionSiegeReady     → 공성병 자체 특성으로 대체
//  ㄴ ActionStabilize      → 수입 구조 단순화로 불필요
//  ㄴ ActionUpgradeCity    → 판이 길어지는 원인, 제거
//  ㄴ ActionWarDec         → 외교 단순화로 흡수
//  ㄴ ActionBlockade       → 초보자에게 개념 설명이 어려움


// ============================================================
//  [룰 02] 외교 단순화
// ============================================================

//  현재: 채팅 커맨드 (-ally / -attack / -peace)
//  변경: 2종으로 축소 + 커맨드 대신 유닛 클릭 방식 검토

//  남기는 것
//  ㄴ 동맹 선언  — 핵심 재미 요소
//  ㄴ 선전포고  — 배신 긴장감

//  제거하는 것
//  ㄴ 휴전 제안  → 자연스럽게 싸움 멈추면 됨, 별도 시스템 불필요
//  ㄴ 통행세 봉쇄, 용병 외교 옵션 → 가스 4종에 흡수

//  입문자용 추가 규칙
//  ㄴ 동맹 중 공격 시 자동 선전포고 처리 (플레이어가 신경 안 써도 됨)
//  ㄴ 전쟁/동맹 상태를 화면 한 곳에 항상 표시


// ============================================================
//  [룰 03] 병종 학습 부담 축소
// ============================================================

//  현재: 5종 (보병/궁병/창병/기병/공성)
//  유지: 5종 — 단, 상성을 화면에 항상 표시

//  입문자 학습 순서 설계
//  1단계 (0~5분):  보병·기병만으로 싸움 가능
//  2단계 (5~15분): 상성 보정 체감 후 창병·궁병 도입
//  3단계 (15분~):  공성병으로 거점 공략

//  시작 지급 유닛을 보병만으로 제한
//  ㄴ 기존: 보병4 + 궁병2
//  ㄴ 변경: 보병5 → 첫 교전에서 상성 없이 싸워보게


// ============================================================
//  [룰 04] 수입 구조 단순화
// ============////////////////////////////////////////////////

//  현재: 도시 등급별 5/10/20 미네랄
//  유지: 동일 — 단, 수입 주기를 빠르게 조정

//  판 길이 조정 핵심 레버
//  ㄴ INCOME_TICK_INTERVAL 줄이면 판이 빨라짐
//  ㄴ 목표: 10분 내 첫 번째 교전, 25분 내 승부 결정

//  수입 표시 의무
//  ㄴ 현재 수입 합계를 항상 화면에 표시
//  ㄴ 도시 점령 시 "+X 미네랄" 텍스트 즉시 출력


// ============================================================
//  [룰 05] 특수유닛 노출 방식 단순화
// ============================================================

//  현재: 도시 점령 → 해금 → 생산 3단계
//  변경: 도시 점령 → 즉시 생산 가능 (해금 절차 제거)

//  추가 규칙
//  ㄴ 특수유닛은 해당 도시에서만 생산 가능 (이동 불가)
//  ㄴ 생산 시 화면에 "특수유닛 생산 가능" 한 줄만 표시
//  ㄴ 일반 유닛과 동일 커맨드, 비용만 약간 높음


// ============================================================
//  [룰 06] 판 강제 종료 장치
// ============================================================

//  20분 경과 시 수입 2배 가속
//  ㄴ 경제 격차가 빠르게 벌어져 자연스럽게 승부 결정

//  25분 경과 시 점령 승리 조건 완화
//  ㄴ 60개 → 50개로 하향 (패망 가속)

//  30분 경과 시 최다 점령 플레이어 자동 승리
//  ㄴ 극단적 장기전 방지
