# 수도와 원격 건설

FranceDp의 실제 수도는 Protoss Nexus가 아니라 Khaydarin Crystal Formation입니다.
UnitModel.nexus_unit에 이 유닛을 등록하고 수도 이름, HP 6500, 실드 500, 방어력 50을 적용합니다.
게이트웨이는 UnitModel.barracks이며 건설 비용은 미네랄 100, 생산 시간은 280입니다.

## 초기 위치

maps/base.scx의 각 시작 거점 안에 P8 Protoss Beacon 마커를 하나씩 넣었습니다.
이 마커는 Terran Beacon 도시 마커와 다릅니다. 시작 위치 중심에서 오른쪽 아래 64픽셀에 배치했습니다.
맵 편집기에서 Protoss Beacon을 옮기면 초기 수도 위치를 변경할 수 있습니다.
마커는 해당 선택 거점 로케이션 안에 있어야 합니다. 파일런 변환과 같은 onPluginStart 단계에서
P8 소유 수도로 변환하고 거점별 EUDVArray(7, CUnit)에 저장합니다. 인트로 동안은 무적입니다.
거점 지급 시 저장한 수도를 점 로케이션에서 GiveUnits로 넘기고 같은 CUnit과 generation을
플레이어별 수도 배열에 전달합니다. 이때 무적을 해제하며 다시 생성하지 않습니다.
기존 SCV 지급은 제거합니다.

선택창 와이어프레임은 FranceDp와 같은 Command Center 외형을 사용합니다.
상태 정보 콜백도 FranceDp의 유닛 정보창으로 바꿔 건물 생산창을 사용하지 않습니다.

## 일반 도시에서 재소환

일반 도시 파일런의 7번 버튼을 누르면 소환 요청 더미 유닛의 생산 큐를 신호로 사용합니다.
더미는 Kakaru (Twilight Critter)이며 실제로 생산하지 않습니다. 큐를 즉시 비우고
버튼을 누른 파일런의 점 로케이션에서 수도를 생성합니다. 초기 마커나 랜덤 위치는 사용하지 않습니다.
플레이어별 수도 CUnit과 generation을 저장해 파괴와 슬롯 재사용을 구별합니다.

RequireData는 없는 유닛을 직접 검사하지 않습니다. 코드에서 살아 있는 수도가 없으면
nexus_requirement(Mineral Field Type 1)의 완료 유닛 카운터를 1, 있으면 0으로 설정합니다.
소환 더미의 RequireData는 이 조건 유닛이 존재해야 한다는 프로그램을 사용합니다.
이 조건 유닛은 맵에 실제로 생성하거나 배치하지 않는 예약 슬롯입니다.

src/data/require_data.json의 unit_overrides에서 소환·게이트웨이 요구사항을 관리합니다.
unit_overrides.orders의 31번 명령은 FranceDp처럼 [65535]로 연결해 수도에서도 프로토스 건설 명령을 사용할 수 있게 합니다.
enabled는 기존 FranceDp 전체 스냅샷 적용 여부이며 unit_overrides.enabled는 두 유닛의 개별 적용 여부입니다.
개별 프로그램은 기존 스냅샷 뒤 word offset 2085부터 예약합니다.
도시의 조건 함수는 CanTrain, 동작 함수는 Train이며 수도의 버튼은 FranceDp WarpBuilding 동작을 사용합니다.
버튼 데이터는 FranceDp와 같은 20바이트 구조로 가능·불가능 설명 ID를 모두 지정합니다.
수도에는 게이트웨이 건설 버튼 하나만, 파일런에는 수도 소환 버튼 하나만 등록합니다.
src/data/custom_tbl.json의 630/631은 건설 가능·불가능 설명, 1049/1050은 소환 가능·불가능 설명입니다.
TBL은 활성화되어 있으며 건설은 G, 소환은 N 단축키를 사용합니다.

## 원격 게이트웨이 건설

수도의 5번 버튼으로 게이트웨이 위치를 선택하면 order 31과 대상 좌표를 읽습니다.
그 위치에 임시 프로브를 만들고 같은 건설 명령·좌표·건물 ID를 넘깁니다.
일반 건물 생산 큐가 아니라 CUnit이 건설 명령에 사용하는 buildQueue1 필드를 전달하는 것입니다.
수도 명령은 바로 비워 반복 건설을 막고, 임시 프로브는 빌드 때 선언한 UnitGroup에서 관리합니다.
건설 관련 명령이 끝나면 프로브를 제거하며 죽은 항목도 매 틱 정리합니다.
게이트웨이만 허용하고, 포지·기술 명령·특수 유닛은 추가하지 않습니다.
지형·건설 공간·사이오닉 전력·자원은 프로브의 실제 건설 동작을 사용합니다.

테스트·별도 코드 검증·빌드는 사용자 요청에 따라 실행하지 않았습니다.
