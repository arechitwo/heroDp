# 유닛 스탯 밸런스 설계 v2

## 핵심 설계 원칙
- **비용 순서**: 보병/창병(20, 저가) < 기병(35, 중간) < 공성병(45) < 기사(70, 고가)
- **HP 높음 / 공격력 낮음** — 교전이 길게 지속되도록 의도적으로 설계
- **WeaponType 3종 = 상성 행렬과 직결**
  - `Normal` = 다수 표준형 (경량100% / 중량70% / 구조물40%)
  - `Anti` = 기사형 Knight (경량100% / 중량100% / 구조물70%)
  - `Explosive` = 구조물 특화형 Siege (경량40% / 중량40% / 구조물100%)
- **size = 방어타입**: `Light`(경량) / `Heavy`(중량). `Medium`은 사용 안 함 — 기존 데이터에 있던 Medium은 전부 Light로 통일.

---

## 기존 데이터에서 발견한 문제점 (수정함)

기존 CSV 값은 다른 게임에서 가져온 placeholder라 역할과 안 맞는 부분이 많았어요:

| 유닛 | 기존 WeaponType | 기존 size | 문제 | 수정 |
|---|---|---|---|---|
| light_infantry (보병) | Anti | Light | 보병은 다수표준형이어야 함 | → Normal |
| light_cavalry (기병) | Anti | Medium | 기병은 다수표준형 + 경량이어야 함 | → Normal / Light |
| knight (기사) | Normal | Heavy | 기사는 기사형(Anti)이어야 함 | → Anti |
| siege_unit (공성병) | Explosive | Heavy | 공성병은 경량 방어여야 함 | → size만 Light로 수정 (WeaponType은 원래도 맞음) |

특수유닛 19종도 거의 전부 원본병종과 WeaponType/size가 불일치했어서, 원본병종 기준으로 전부 재배정했습니다 (예: `leuze_goliath`는 기사 계열 요충지인데 기존 size=Heavy/WeaponType=Normal이었던 걸 Anti로 수정, `arras_dragoon`은 공성병 계열인데 기존 WeaponType=Anti였던 걸 Explosive로 수정 등).

| 유닛 | WeaponType | size | 공격력(지상/공중) | 방어력 | 사거리 | 공격속도 | HP | 비용 |

### 역할별 설계 의도가 수치에 어떻게 반영됐는지

- **창병**: 근접 다수형, 무난한 방어력(18). 확장 주력으로서 보병보다 살짝 더 단단하게.
- **보병**: 원거리 + 대공 가능. 사거리(128)로 거리를 두고 싸우는 대신 공격력은 낮게(35) 잡아 "물량으로 밀어야 하는" 느낌.
- **기병**: 가장 높은 단발 공격력(75)이지만 방어력(12)·HP(1300) 모두 최저. **공격속도(28, 가장 느림)로 한방의 무게감을 표현** — 말씀하신 "한방한방이 강한 유닛"을 의도대로 구현. 정면 대결보다는 약해진 적(수비대 전멸 직전)을 잡고 빠지는 역할에 맞게 설계됨.
- **공성병**: 사거리 224(가장 길음), 공격력 85로 수치 자체는 강해 보이지만 **유닛 상대로는 40%만 적용**돼서 실질 위력은 34 수준 — 포탑(Structure) 상대로만 85 그대로 들어감. "포탑 없으면 계륵"이 정확히 구현됨.
- **기사**: HP 4200(전체 최고), 방어력 38(전체 최고)로 압도적 탱커. `upgrade_ad=3`으로 다른 유닛(1)보다 업그레이드 시 공격력이 3배 더 오르게 설정 — "업그레이드 할수록 강해짐"을 수치로 구현.

## 교전 시뮬레이션 (1:1 기준, 참고용)

방어력 적용 후 실제 들어가는 데미지 = (공격력 − 방어력) × 상성배율. 시간당 데미지(DPS) = 실제데미지 ÷ 공격속도.

| 대결 | 결과 | 비고 |
|---|---|---|
| 창병 vs 보병 | **창병이 약 1.9배 빠르게 승리** (804틱 vs 1500틱) | 둘 다 확장 주력이지만 근접 창병의 화력이 방어를 더 잘 뚫음 |
| 기병 vs 보병 | **기병이 근소하게 승리** (689틱 vs 848틱) | 의도된 결과 — 기병(cost35)이 보병(cost20)보다 비싸므로 1:1 우위는 자연스러움. 다만 보병은 물량으로 압도 가능 |
| 기사 vs 보병 (1:1) | **기사 완전 압도** — 보병은 데미지를 전혀 못 줌 | 보병 공격력(35)이 기사 방어력(38)보다 낮아 타입 보정 전부터 0 데미지. 기사는 보병 단독으로는 사실상 무적 |

> 무재브의 영웅 Zergling(기병 계열, 근접)은 사거리 페널티가 없어 일반 보병을 약 3배 빠르게 제압함(370틱 vs 1143틱) — "근접 기병은 보병을 압도해도 된다"는 의도에 부합하는 결과로 확인됨.
>
> 기사는 1:1에서 보병에게 사실상 무적이에요(공격력이 방어력보다 낮아 0데미지). "기사 카운터는 기사"라는 의도에는 맞지만, 다수 물량으로도 전혀 못 긁는 건 의도하신 정도보다 더 극단적일 수 있어요.

## 확인이 필요한 부분

### 1. medic, balloon 행 — 용도 불명
`normalUnits.csv`에 있던 두 행(`medic`, `balloon`)은 우리 5병종(보병/창병/기병/공성병/기사) 체계에 속하지 않아요. 공격력 0, HP만 있고 timeCost가 채워진(300, 400) 유일한 행들이라 다른 용도(주둔군? 회복 유닛? 가스 액션용?)로 보이는데, 일단 원본 값 그대로 손대지 않고 보존했어요. 어떤 용도인지 알려주시면 맞게 채울게요.

### 2. 특수유닛 cost(175 균일) vs 새 일반유닛 cost(20~70) 비율 불균형
일반유닛 cost를 새로 20~70 스케일로 잡으면서, 특수유닛(전부 175 고정)과의 비율이 원본별로 차이가 커요:

| 원본 | 일반 cost | 특수 cost | 비율 |
|---|---|---|---|
| 보병/창병 | 20 | 175 | 8.75배 |
| 기병 | 35 | 175 | 5배 |
| 공성병 | 45 | 175 | 3.9배 |
| 기사 | 70 | 175 | 2.5배 |

보병/창병 계열 특수유닛이 상대적으로 훨씬 비싼 업그레이드가 되는 구조예요. 의도하신 거라면 그대로 두고, 아니라면 특수유닛 cost도 원본별로 차등을 둘 수 있어요.

### 3. 기사 1:1 압도 정도
시뮬레이션상 기사 1기가 보병 1기를 상대로 매우 크게 이기는데, 다수 물량으로 상쇄되는 정도는 실제 플레이테스트가 필요해요. 너무 강하다고 느껴지면 armor나 HP를 낮춰 조정 가능합니다.
