# 특수유닛 최종 확정표 v6

## 변경 이력 (v5 → v6)
- **전면 재설계**: 새 역할 정의에 따라 거점·요충지 구조 전체 재배치
  - 거점 7개 = 보병/창병만 (확장 주력)
  - 기사 경쟁 지대 4곳 = 거점들 사이, 7인이 경쟁하는 핵심 지점
  - 공성병 3곳 = 거점 인접 외곽 (포탑 카운터 전용, 초반엔 계륵)
  - 기병 5곳 = 거점↔기사지대 사이 (빠른 기동, 주둔 몸빵 견제)
- **SC1 정식 유닛명 표기**로 전환 (종족 접두사 포함)

---

## 역할 재정의 (핵심 설계 원칙)

| 병종 | 역할 | 특징 |
|---|---|---|
| 보병 (Terran Marine) | 확장 주력 | 초반부터 끝까지 범용으로 유용 |
| 창병 (Protoss Zealot) | 확장 주력 | 보병과 함께 영토 확장의 핵심 |
| 기병 (Terran Vulture) | 견제·기동 | 빠른 기동성 + 주둔 몸빵으로 적의 보병/창병 침투 견제 |
| 공성병 (Terran Siege Tank) | 포탑 카운터 | 포탑 없으면 쓸모없음. 포탑 등장 전까지 초반엔 계륵 |
| 기사 (Zerg Ultralisk) | 후반 핵심 | 비싸고 소수, 업그레이드로 강해짐. 후반은 기사전으로 수렴 |

> 확장에는 보병·창병이 유리. 포탑이 생기는 시점부터 공성병이 필요해지며, 기사는 물량은 적지만 후반 결전 병기.
