# 인컴과 대도시

설정은 src/data/diplomacy.json에서 관리한다. 게임 시작 후부터 타이머가 진행되며, 시작 설정 화면에서는 수입이 발생하지 않는다. 아래 초 단위는 24프레임을 기준으로 한 설계상 표현이다.

| 항목 | 값 |
|---|---:|
| 시작 자금 | 500금 |
| 일반 도시 세금 | 4320프레임(3분)마다 도시당 50금 |
| 수도 기본 수입 | 192프레임(8초)마다 5금, 세력당 한 번 |
| 대도시 추가 수입 | 완성된 대도시당 192프레임(8초)마다 5금 |
| 대도시 건설비 | 600금 |
| 대도시 건설 시간 | 720프레임 |
| 대도시 한도 | max(1, 일반 도시 수 / 3의 정수 몫) |

대도시 한도는 엔진 전체 유닛 수 테이블 0x582324를 사용한다. 완성·건설 중인 건물과 수도로 승계한 대도시를 포함하며 대리 프로브 예약은 별도로 세지 않는다. 건설 중 수만 필요하면 전체 수에서 완성 수 테이블 0x584DE4의 값을 빼면 된다. [BWAPI의 미완성 수 계산](https://github.com/bwapi/bwapi/blob/main/bwapi/BWAPILIB/Source/Player.cpp)도 전체 수에서 완성 수를 빼는 방식이다.

빠른 연속 건설로 한도를 넘긴 경우 commander.trackNewUnits에서 신규 대도시마다 엔진의 전체 수를 바로 읽고 한도를 초과했으면 해당 건물을 제거하고 건설비 600금을 전액 반환한다. 신규 건물은 건설 시작 상태로 들어오므로 완성 여부를 재검사하지 않는다. 준비 단계·초과분 배열·별도 예약 카운터는 사용하지 않는다. 영토를 잃어 한도를 넘겨도 기존 건물은 유지한다. 일반 건설비 차감과 정상 건설 취소 환불은 엔진에 맡기며 별도의 자원 중복 차감은 없다.

대도시는 완공된 뒤에만 추가 수입을 준다. 대도시 자체는 일반 도시 세금 계산에 넣지 않는다. 수도가 없어져도 다른 완성 대도시의 추가 수입은 유지한다.

일곱 시작 거점은 maps/base.scx의 지명 로케이션을 넓혀 각각 도시 파일런 5개를 지급한다. 붙어 있는 다중 파일런 도시를 쪼개지 않고 주변 도시를 포함한다. 시작 영역은 영토 지급용이며 시작 병력 생성과 첫 화면은 지급받은 수도 위치를 기준으로 한다. 시작 자금은 1000금에서 500금으로 낮췄다.

대도시는 Protoss Arbiter Tribunal을 사용한다. RequiresPsi를 켜서 파일런 동력 범위 안에서만 프로토스 건설 엔진이 배치를 허용한다. 건설 배치·충돌 영역은 128×128픽셀(4×4타일)로 넓혀 승계 수도가 들어갈 자리를 확보한다. 버튼셋은 제거한 상태를 유지한다. 기존 트리뷰널의 선행 테크 대신 수도 보유 요구사항에 연결한다.

수도가 파괴되면 등록된 대도시 UnitGroup에서 먼저 확인된 완성 대도시를 선택한다. 건설 중인 대도시는 제외한다. 해당 건물의 좌표를 캐싱하고 제거한 뒤, 충돌 영역이 비워지는 다음 틱에 저장한 좌표에서 수도를 생성해 수도 EPD·세대·활성 상태에 등록한다. 생성에 필요한 유닛 슬롯이 없으면 같은 좌표를 유지하고 이후 틱에 재시도한다. 승계 대기 중에는 다른 후보를 제거하거나 일반 도시에서 수도를 중복 소환하지 않는다. 대도시 한도 사용은 대기 중에도 유지하며 수입은 수도 생성 후 재개한다. 승계된 수도는 수도 수입 5금만 제공한다. 대도시 수입을 중복 지급하지 않으며 건설 한도는 한 자리를 계속 사용한다. 이 수도가 다시 파괴되면 수입과 한도 사용이 사라진다. 완성 대도시가 없으면 기존 일반 도시의 수도 소환 방식을 사용한다.

예를 들어 수도 하나와 대도시 하나의 8초 주기 수입은 총 10금이다. 수도가 파괴되어 대도시가 승계하면 수도 하나만 남으므로 총 5금으로 줄어든다. 일반 도시 세금은 별도다.

대도시는 기존 신규 유닛 순회에서 한 번만 등록한다. 매 틱 UnitGroup의 죽은 항목을 정리하고 완성된 건물 수와 수도 후보를 갱신한다. 세력별 전체 유닛 재검색은 하지 않는다. 기본 세금은 기존 도시 수 캐시를 사용한다.

## 구매력

지급액은 유지하고 지급 간격을 늘렸다. 도시 세금은 30초에서 3분으로, 수도·대도시 수입은 2초에서 8초로 바꿔 돈이 빠르게 계속 쌓이는 속도감을 줄인다. 도시 5개라면 3분마다 세금 250금을 받으며 수도·대도시는 각각 8초마다 5금을 준다. 군영 생산 주기는 720프레임(30초)을 유지한다.

대도시 투자금은 5금씩 120회 지급받으면 회수한다. 지급 주기 기준 완공 후 약 16분이며 실제 첫 지급 시점은 공용 수입 타이머에 따른다. 시작 병력은 창병 8기다. 군영 생산은 ARMY_CAMP.md를 따르며 군영 건설비는 150금이다.

이번 변경은 사용자 지침에 따라 빌드·테스트·별도 코드 검증을 실행하지 않았다.
