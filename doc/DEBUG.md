# 인게임 디버그

`src/data/diplomacy.json`의 `debug_enabled`가 `true`일 때 참가자가 사용합니다.
`false`이면 디버그 동작을 끕니다. 명령은 기존 chatEvent → MSQC 채널로 동기화됩니다.
채팅 `디버그`를 입력하면 도움말을 표시합니다. 시작 UI 전후 모두 사용 가능합니다.

플레이어별 적용 값은 기본 10000, 생성 개수는 기본 1입니다.
`디버그 값 0/1/24/120/400/720/10000/100000` 중 하나를 입력해 값을 선택합니다.
임의 값은 `디버그 값 초기화` 후 `디버그 숫자 0`부터 `디버그 숫자 9`까지로 자릿수를 추가합니다.
예를 들어 250은 초기화 → 숫자 2 → 숫자 5 → 숫자 0 순서입니다. 최대값은 2,000,000,000입니다.

| 채팅 명령 | 동작 |
|---|---|
| `디버그 돈` | 내 미네랄을 적용 값으로 설정 |
| `디버그 가스` | 내 가스를 적용 값으로 설정 |
| `디버그 자원` | 내 미네랄·가스를 모두 적용 값으로 설정 |
| `디버그 개수 1/10/100` | 다음 유닛 생성 개수 선택 |
| `디버그 마린` | 내 마우스 위치에 내 마린 생성 |
| `디버그 SCV` | 내 마우스 위치에 내 SCV 생성 |
| `디버그 세금타이머` | 공용 세금 경과 틱 설정. 720 이상이면 다음 세금 처리에서 지급 |
| `디버그 주둔군타이머` | 마우스 주변 ±160픽셀의 전투 도시 잔여 틱 설정 |
| `디버그 시작타이머` | 거점 선택 완료 후 시작 카운트다운의 경과 틱 설정 |

주둔군 타이머는 이미 전투 중인 도시에만 적용합니다. 값 0은 정상 회수를 위해 1로 바꾸며,
공격이 계속되면 기존 도시 코드에 의해 타이머가 다시 갱신됩니다. 최대값은 65535입니다.
세금·시작 타이머는 공용 게임 상태에 적용되므로 모든 참가자에게 영향을 줍니다.
생성한 마린은 기존 신규 유닛 등록 흐름을 통해 기본 UnitGroup에 들어갑니다. SCV는 전군 명령에서 제외됩니다.

코드에서는 `debug.spawn(player, unit, count)`, `debug.setMinerals(player, amount)`,
`debug.setGas(player, amount)`, `debug.setTaxTimer(ticks)`,
`debug.setGarrisonTimer(player, ticks)`, `debug.setStartTimer(ticks)`를 호출할 수 있습니다.
