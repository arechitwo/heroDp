# 인게임 디버그

`src/data/diplomacy.json`의 `debug_enabled`가 `true`일 때 참가자가 사용합니다.
`false`이면 디버그 동작을 끕니다. chatEvent의 `__ptrAddr__`·`__patternAddr__`로 패턴을 받고
고려시대 코드와 같은 `parse()` 방식으로 숫자를 읽은 뒤 MSQC로 동기화합니다.
채팅 `디버그`를 입력하면 도움말을 표시합니다. 시작 UI 전후 모두 사용 가능합니다.

debug_enabled가 true이면 첫 게임 틱에서 인트로·모드 설정·세력 선택·시작 카운트다운을 건너뛰고 개인전/시야만 설정으로 시작합니다. 거점은 슬롯 순서로 고정 배정합니다(P1 스트라스부르, P2 울름, P3 아우크스부르크, P4 뮌헨, P5 뉘른베르크, P6 레겐스부르크, P7 잘츠부르크). 도시·수도·초기 자원·창병 지급은 일반 start() 경로를 그대로 사용합니다. false이면 기존 시작 UI와 선택 절차를 사용합니다.

플레이어별 적용 값은 기본 10000, 생성 개수는 기본 1입니다.
`디버그 돈 50000`, `디버그 마린 10`처럼 명령 뒤에 숫자를 바로 입력합니다.
`디버그 값 250`은 기본 적용 값, `디버그 개수 10`은 기본 생성 개수를 바꿉니다.
숫자를 생략하면 기본값을 사용합니다. 자원·타이머 최대값은 2,000,000,000, 생성 개수는 0–255입니다.

| 채팅 명령 | 동작 |
|---|---|
| `디버그 돈 50000` | 내 미네랄을 50000으로 설정 |
| `디버그 미네랄 50000` | 내 현재 미네랄을 50000으로 설정. 기존 돈 명령과 동일하며 더하는 것이 아니라 대입 |
| `디버그 가스 50000` | 내 가스를 50000으로 설정 |
| `디버그 자원 50000` | 내 미네랄·가스를 모두 50000으로 설정 |
| `디버그 개수 10` | 기본 유닛 생성 개수를 10으로 설정 |
| `디버그 마린 10` | 내 마우스 위치에 내 마린 10기 생성 |
| `디버그 SCV 1` | 내 마우스 위치에 내 SCV 1기 생성 |
| `디버그 병종` | 마우스 위치에 창병·경보병·장궁병·경기병·공병·기사·공성 터렛을 각각 1기 생성 |
| `디버그 세금타이머 720` | 공용 세금 경과 틱 설정. 720 이상이면 다음 세금 처리에서 지급 |
| `디버그 주둔군타이머 120` | 마우스 주변 ±160픽셀의 전투 도시 잔여 틱 설정 |
| `디버그 시작타이머 120` | 거점 선택 완료 후 시작 카운트다운의 경과 틱 설정 |

숫자를 포함한 명령도 다음 숫자 생략 명령의 기본값을 갱신합니다.
`디버그 병종`은 기본 생성 개수와 관계없이 각각 1기씩 생성합니다. combat.json에 등록된 병종을 빌드 때 목록으로 만들므로 이후 추가한 병종도 포함됩니다. 도시·수도·별도 디버그 짐 레이너는 병종 목록에 포함하지 않습니다.
채팅 패턴은 플러그인이 지원하는 `^시작.*중간.*끝$` 형식을 사용합니다.
접두사 길이는 플러그인과 같은 UTF-8 바이트 기준으로 계산합니다.
24비트 MSQC 전송값 두 개에 숫자의 하위 24비트와 상위 바이트·명령을 나눠 담습니다.
로컬 파싱 결과로 게임 상태를 바로 바꾸지 않으며 수신된 값만 적용합니다.

주둔군 타이머는 이미 전투 중인 도시에만 적용합니다. 값 0은 정상 회수를 위해 1로 바꾸며,
공격이 계속되면 기존 도시 코드에 의해 타이머가 다시 갱신됩니다. 최대값은 65535입니다.
세금·시작 타이머는 공용 게임 상태에 적용되므로 모든 참가자에게 영향을 줍니다.
생성한 마린은 기존 신규 유닛 등록 흐름을 통해 기본 UnitGroup에 들어갑니다. SCV는 전군 명령에서 제외됩니다.

코드에서는 `debug.spawn(player, unit, count)`, `debug.setMinerals(player, amount)`,
`debug.setGas(player, amount)`, `debug.setTaxTimer(ticks)`,
`debug.setGarrisonTimer(player, ticks)`, `debug.setStartTimer(ticks)`를 호출할 수 있습니다.
