# 공격·방어 타입

표시 공격력은 한 번의 타격이 낼 수 있는 최대 피해다. 업그레이드로 공격력이 오르면 최대값도 오른다. 타입 배율은 100%를 넘지 않는다.

| 공격 / 방어 | 보병 | 기갑 | 영웅 |
|---|---:|---:|---:|
| 일반 | 100% | 75% | 75% |
| 관통 | 75% | 100% | 100% |
| 공성 | 50% | 100% | 25% |

배율은 resource/units/damage_types.json에서 관리한다. 기본 병종별 배정은 combat.json의 defense.type과 attack.ground.type, attack.air.type으로 지정한다.

| 병종 | 공격 | 방어 |
|---|---|---|
| 창병 | 관통 | 보병 |
| 경보병 | 일반 | 보병 |
| 경기병 | 일반 | 기갑 |
| 공성병 | 공성 | 기갑 |
| 기사 | 일반 | 기갑 |
| 도시·훈련소·수도 | 기존 무기 유지 | 기갑 |
| 주둔군 | 기존 무기 유지 | 보병 |

영웅 4~5종을 정할 때 병종과 관계없이 defense.type을 hero로 지정한다. 현재는 영웅 방어 타입만 마련하고 실제 영웅 병종을 추가하지 않는다.

엔진의 damageType 1/2/3과 sizeType 1/2/3을 역할에 대응시킨다. 0x515B84의 행은 20바이트이며 타입 번호 DWORD 다음에 Independent/Small/Medium/Large 배율이 들어간다. 배율의 100%는 256이다. 그래픽 크기·충돌 크기는 방어 타입과 별개다.

엔진은 HP 피해에서 방어력을 먼저 차감한 다음 타입 배율을 적용한다. 실드는 기존 엔진 규칙을 유지하며 이 타입 배율을 적용받지 않는다. 여러 타격이나 범위 공격의 합계는 단일 타격 표시 공격력과 구분한다.
