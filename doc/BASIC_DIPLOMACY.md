# 기본 디플로메시

현재 진입점은 `src/game/main.eps`입니다. FranceDp 주둔군과 koreaDp 스타일 시작 UI를 사용합니다.

| 모듈 | 기능 |
|---|---|
| `cities.eps` | 도시 소유권, 주둔군 생성·회수, 점령, 도시 수 캐시 |
| `income.eps` | 일정 트리거 틱마다 도시 수에 비례한 세금 지급 |
| `commander.eps` | MSQC로 동기화한 F+좌·우클릭 전군 명령 |
| `start_ui.eps` | 오프닝, 방장 빠른/세부 설정, 채팅 거점 선택, 게임 시작 |
| `rules.eps` | 개인전 동맹 규칙, 대기열/랜덤 팀 구성, 팀 동맹과 시야 |
| `unit_dat.eps` | `TrgUnit`/`Weapon` 문법의 파일런·주둔군 외형, 스탯, 공격 AI |

## 초기 맵 설정

`src/plugins/map_setup.py`가 빌드 중 P1–P7을 사람, P8을 컴퓨터 도시 소유자로 설정합니다.
종족은 기본 Terran입니다. P1–P7 시작 위치를 추가하지만 도시 마커 260개는 비콘 그대로 남깁니다.
게임에 진입한 뒤 `onPluginStart()`에서 `unitDat.init()` → `cities.init()` 순서로 실행합니다.
외형·공격 AI·버튼 제거 설정이 끝난 뒤 비콘을 지우고 같은 위치에 파일런을 생성해 무적으로 설정합니다.
변환은 빌드 단계에서 하지 않으며, 도시 소유권은 방어 병력의 전투 결과로 바뀝니다.
게임 엔진용 로케이션은 빌드 출력에만 생성하므로 원본 `maps/base.scx`의 비콘과 빈 로케이션은 보존됩니다.

도시 로케이션은 데이터의 기존 슬롯 1–231(64 제외), Anywhere는 64,
주둔군 생성 임시 영역은 232, 마우스 목표는 240–246, 시작 위치는 247–253,
명령 선택/비콘 변환은 254, MSQC 임시 영역은 255입니다.
새 로케이션을 추가할 때 예약 슬롯과 충돌하지 않게 합니다.

## 시작 UI

koreaDp의 오프닝 → 방장 설정 → 국가 선택 흐름을 신규 맵의 거점 선택에 맞췄습니다.
120틱 오프닝 뒤 방장(참가자 중 가장 낮은 슬롯)이 빠른 설정을 선택합니다.

- 1: 개인전·선택·시야만
- 2: 개인전·랜덤·시야만
- 3: 팀전·선택
- 4: 팀전·랜덤
- 0: 세부 설정

빠른 설정은 ↑↓ 이동, → 또는 Y로도 확정합니다. 세부 설정은 ↑↓ 항목 이동, ←→ 변경이며
게임 종류·거점 선택 방식·개인전 동맹 허용 여부를 정합니다. 팀전은 대기열 또는 랜덤으로 팀을 나눕니다.
개인전의 동맹 설정은 가능/시야만/불가능을 지원하며, 시야만에서는 공격 동맹을 막고 공유 시야 선택을 허용합니다.
팀전은 같은 팀 동맹과 공유 시야를 유지합니다.
현재 구현하지 않은 경험치 배율·팀전2 팩션·조장 지명 메뉴는 표시하지 않습니다.

거점 선택에서는 채팅으로 `거점1`~`거점7` 또는 `랜덤`을 입력합니다. 숫자 1~7도 지원합니다.
중복 선택을 막으며, 개인전은 동시에 선택하고 팀전은 양 팀이 번갈아 선택합니다.
600틱 동안 선택하지 않으면 남은 거점을 무작위 배정합니다. 모두 선택하면 120틱 뒤 시작합니다.
로컬 채팅은 `chatEvent` → MSQC → 플레이어별 수신 배열로 동기화한 후 적용합니다.
선택 중에는 P8의 도시 시야를 공유하며, 게임 시작 시 공유를 해제합니다.
각 참가자는 선택한 거점의 도시와 Marine 8기, SCV 1기, 미네랄 500을 받습니다.
혼자 실행할 때는 개인전 선택/랜덤으로 시작합니다. 팀전은 2명 이상이어야 합니다.
도시가 2·3개인 거점은 해당 파일런 수만큼 도시로 계산합니다.

## 주둔군과 점령

파일런이 FranceDp와 같은 Tower Attack(명령 19) 상태가 되면
도시 파일런당 Broodling 6기를 생성하고 도시 HP를 30%로 낮춥니다.
주둔군은 파일런 기준 (-32,+32)부터 16픽셀씩 옮기며 생성하고, 지상·정지 상태로 고정합니다.
Broodling은 마린 외형·초상화·음성, 정지 공격 AI를 사용하는 주둔군입니다.
DAT 수정 범위는 파일런 156과 주둔군 40 및 전용 무기 117/119입니다. 실제 마린 0 등 일반 유닛은 수정하지 않습니다.
260개 도시 전체에 상시 주둔군을 깔지 않고 전투가 생긴 거점에만 생성합니다.

주둔군을 포함한 도시 소유자의 Men이 사라지면 FranceDp처럼 `CommandMostAt`으로
주변 병력이 가장 많은 플레이어에게 거점의 파일런을 넘깁니다. 동률은 원본처럼 낮은 슬롯 우선입니다.
점령 시 HP·쉴드를 100% 복구합니다. 공격 상태가 끊긴 뒤 400틱이 지나면 주둔군을 회수하고 HP를 복구합니다.
퇴장한 사람의 도시는 P8로 되돌립니다.
도시는 프레임당 16거점씩 순환 검사하므로 판정은 한 순회만큼 늦을 수 있습니다.

## 세금과 전군 명령

720틱마다 원본 거점의 소유 도시 하나당 20미네랄을 지급합니다.
새로 건설한 파일런은 세금 도시 수에 포함되지 않습니다.
F를 누른 상태로 우클릭하면 전군 이동, 좌클릭하면 전군 공격입니다.
일꾼·주둔군·건물은 전군 명령에서 제외하고, 전투 유닛 및 수송·지원 유닛에 적용합니다.
MSQC가 마우스 위치와 입력을 동기화하므로 로컬 입력을 직접 게임 상태에 적용하지 않습니다.

수치는 `src/data/diplomacy.json`에서 수정합니다. 주기는 트리거 틱이며 실제 시간은 게임 속도에 따라 달라집니다.
파일런·주둔군의 DAT는 `src/game/modules/unit_dat.eps`에서 직접 편집합니다. 예:

```eps
TrgUnit(156).maxHp = 2000 * 256;
TrgUnit(40).flingy = 78; // 마린 외형
Weapon(119).damage = 80;
```

특수유닛과 나머지 일반 유닛 스탯 변경은 아직 적용하지 않았습니다.
FranceDp의 TBL·RequireData 스냅샷도 기본 비활성 상태입니다.

## 검증

euddraft 실제 빌드 및 freeze 처리를 확인했습니다. 맵 설정 테스트는 7개 사람 슬롯과 시작 위치,
260개 비콘 유지, 도시 로케이션 간 다른 도시가 섞이지 않는지 검사합니다.
`python -m unittest discover -s tests -v`로 실행합니다.
인게임과 여러 사람이 참여하는 멀티플레이 검증은 별도로 필요합니다.
