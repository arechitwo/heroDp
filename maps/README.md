# 베이스 맵

`base.scx`는 PR #1의 Europe_Inland_v3를 수정한 베이스입니다.
256×256 Jungle 지형이며, 로케이션 이름의 도시 수를 읽어 P8 Terran Beacon(195)을 배치했습니다.

- 230개 거점: 1개 배치 210곳, 2개 배치 10곳, 3개 배치 10곳. 총 260개 비콘.
- 한 개는 중앙, 두 개는 중앙 기준 좌우 16픽셀, 세 개는 왼쪽 하나와 오른쪽 위·아래로 배치.
- 세 개의 상대 좌표: `(-16, 0)`, `(16, -16)`, `(16, 16)`.
- 32×32픽셀을 파일런 하나의 크기로 간주하며 서로 겹치지 않음을 검사했습니다.
- Anywhere를 포함한 MRGN 255슬롯을 모두 비웠습니다. 지형 등 다른 CHK 섹션은 그대로 보존했습니다.

삭제한 로케이션 이름·중심·도시 수·비콘 좌표는 `src/data/city_markers.json`에 보존했습니다.
수정 도구는 `tools/place_city_markers.py`이며, 원본 로케이션이 있는 SCX를 입력으로 사용합니다.
루트 `Europe_Inland_v3.scx`는 수정본, `Europe_Inland_v3.original.scx`는 다운로드한 원본입니다.
실제 게임 내 표시와 이동 가능 여부는 아직 확인하지 않았습니다.
