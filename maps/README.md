# 베이스 맵

`base.scx`는 유럽 내륙 지형 `Europe_Inland_v3.scx`입니다. 256×256 Jungle 타일셋이며 프랑스 동부–독일–보헤미아–알프스 일대의 실제 고도와 수계를 바탕으로 제작했습니다.

- 도시 예정 자리 260개, 거점 로케이션 230개(Anywhere 별도)
- 육지 medium 이상, 수면 low·이동불가
- v2에서 수정한 숲 장애물 2,257타일을 외형이 같은 medium·이동불가 타일로 교체
- 도시·영웅 유닛과 전투 트리거는 아직 배치하지 않음

타일 직접 배치 방식입니다. ISOM 자동 지형 연결 데이터는 재생성하지 않았으므로 타일 편집으로 수정합니다. 게임 내 실행과 대규모 부대 통행 테스트는 아직 수행하지 않았습니다.
