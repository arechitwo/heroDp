# 베이스 맵

`base.scx`는 PR #1의 Europe_Inland_v3를 수정한 베이스입니다.
256×256 Jungle 지형이며, 로케이션 이름의 도시 수를 읽어 P8 Terran Beacon(195)을 배치했습니다.

- 230개 거점: 1개 배치 210곳, 2개 배치 10곳, 3개 배치 10곳. 총 260개 비콘.
- 한 개는 중앙, 두 개는 중앙 기준 좌우 16픽셀, 세 개는 왼쪽 하나와 오른쪽 위·아래로 배치.
- 세 개의 상대 좌표: `(-16, 0)`, `(16, -16)`, `(16, 16)`.
- 32×32픽셀을 파일런 하나의 크기로 간주하며 서로 겹치지 않음을 검사했습니다.
- 도시별 고정 영역 230개는 삭제했습니다. 이름이 있는 공용 로케이션 1–21과 Anywhere(64)만 남깁니다.
- `src/game/modules/map_data.py`의 `Loc`에 `EncodeLocation` 이름을 선언합니다. 나머지 233슬롯은 비어 있습니다.
- 21번 `settings_view`는 왼쪽 상단 (0, 0)의 점 로케이션입니다. 오프닝과 게임 설정 메뉴에서 화면을 고정합니다.
- P1–P7은 사람, P8은 컴퓨터이며 P1–P8 종족은 테란입니다.
- P8은 포스2입니다. `OWNR`(게임용)와 `IOWN`(편집기용)을 모두 컴퓨터로 유지합니다.
- 초기 수도는 각 시작 거점 내부의 P8 Protoss Beacon 마커로 지정합니다. 파일런 변환과 같은 초기화 시점에 수도로 바뀌며, 거점 선택 때 저장한 수도를 넘깁니다. 마커를 직접 옮겨 위치를 편집할 수 있습니다.
- 편집기 저장 후 두 값이 달라지면 빌드 런처가 `IOWN`을 기준으로 원본 맵의 `OWNR`를 맞춥니다. 포스·지형·배치 유닛은 그대로 둡니다.
- SCX 수정 후 MPQ를 flush·compact하여 이전 CHK 블록을 정리합니다.

선택 거점 트리거 로케이션 12–18은 스트라스부르·울름·아우크스부르크·뮌헨·뉘른베르크·레겐스부르크·잘츠부르크로 이름을 지정했습니다.
이 로케이션은 플레이어 번호에 귀속되지 않으며, 선택한 플레이어에게 거점을 지급하는 영역입니다. 실제 Start Location 유닛과는 별개입니다.

도시 정보 JSON은 사용하지 않습니다. 도시 수는 UNIT 비콘에서, 시작 거점 도시 수는 시작 위치 영역에서 읽습니다.
최초 비콘 배치 도구는 작업 완료 후 삭제했습니다. SCX 접근용 공용 모듈은 `tools/scx_archive.py`입니다.
루트 `Europe_Inland_v3.scx`는 수정본, `Europe_Inland_v3.original.scx`는 다운로드한 원본입니다.
실제 게임 내 표시와 이동 가능 여부는 아직 확인하지 않았습니다.
